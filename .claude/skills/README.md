# Unity skills

These skills are copied from [Unity-Technologies/skills](https://github.com/Unity-Technologies/skills)
at commit `b7cc0c0`. They are licensed under the Unity Companion License (see `UNITY_SKILLS_LICENSE.md`).
Claude Code loads them automatically for this repository.

| Skill | Use it for |
| --- | --- |
| `ui`, `ui-ugui` | Any change to the uGUI canvases in `GameScene` and `mainMenu` |
| `optimize-text-mesh-pro` | Font assets in `Assets/Busara/Font` and TMP text settings |
| `manage-sprite-atlas` | Packing the UI, theme and piece sprites into atlases |
| `sprite-editor` | Sprite borders (nine-slice), pivots and slicing |
| `optimize-web` | The WebGL build |
| `unity-cli`, `project-auditor-fixes` | Driving the Editor, builds, tests, and Project Auditor fixes |

To update them, run `npx skills add Unity-Technologies/skills`. Alternatively, copy the folders again from a newer commit.
