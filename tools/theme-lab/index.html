Fourteen directions

Directions

Each direction is a complete skin: board, frame motif, hole profile, a piece set for all four resources and the interface colours. Every one is tied to a real culture or to a kingdom from the Busara deck, so a player who picks one is choosing a story as well as a look.

Past, future, fusion

Busara draws on ancient kingdoms and kingdoms that do not exist yet. The two eras use opposite rules on purpose, and fusion boards take one rule from each.

The readability contract

Whatever the theme, Water stays blue, Fire stays red, Air stays amber and Earth stays dark. Each resource also keeps its own glyph silhouette, so the board still reads for colour-blind players and in a quick glance across the table.

Material library

Every piece material the engine can render: African woods, hides and fibres, metals, stones and gems from real sources, plus engineered and fictional materials for future kingdoms. Any of these can go on any board in the workshop.

Holes & states

Eight hole profiles, shown on the surface of the board loaded above. Each row shows the states a slot can be in during play. The highlighted row is this theme's own profile.

Interface

The player panel, the six actions and the kingdom power, skinned by the loaded theme. Past themes use carved, notched buttons; future themes use thin outlines and pills. Change the board at the top and this panel follows.

Workshop

Combine a board from one era with pieces from another, change any piece's material or tint, and swap the hole profile. The spec below the preview drops straight into the theme engine, which generates the matching sprites.

Game-ready sprites

        
The same engine that draws this page renders transparent PNGs for Unity. One command writes fifteen sprites and a manifest per theme into Assets/Busara/Sprites/Themes, sized for the current board and slot prefabs.

      

      

        

          

        

        

          

          
    
            
  1. Generate
    Run node tools/theme-lab/export-sprites.mjs, or pass theme ids to render a subset. It rasterises with Chromium, so the PNGs match this page.
    2. 
            
  2. Import
    In Unity, run Tools > Busara > Board Themes > Import Themes From Sprites. It builds a BoardTheme asset per folder and updates ThemeCatalog.
    3. 
            
  3. Play
    ThemeManager in GameScene skins each board, its slots and every piece placed, moved or traded onto it.
    4. 
            
  4. Let players choose
    Player setup shows a theme picker on every row; Busara Classic keeps the original look.
