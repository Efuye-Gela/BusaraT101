# Decisions

## D-001 — All fifteen powers online as ruleset v3

- Date: 2026-10-07
- Status: active
- Decision: new rooms use `busara-online-v3` (all fifteen kingdoms); v1/v2
  saved matches keep their rules unchanged.
- Reason and evidence: user priority 1 was full power parity; saved rooms must
  never be silently upgraded. Domain tests mirror offline power tests.
- Consequences: the Cloud Code module and Web client must deploy together.
- Reconsider if: a v3 rule is found to differ from offline behaviour.

## D-002 — Online power specifics

- Date: 2026-10-07
- Status: active
- Decision: a power is the turn's action; Necklace cancels any committed
  power; Dome applies to weapons only; Retraction is offered after an action
  and its payment stays spent; Time uses a durable extra-turn queue;
  Manipulation's owner acts on the active seat's board and pays from that
  seat's virtues, without Trade; Imagination offers all six virtue types when
  the target's virtues are hidden.
- Reason and evidence: these follow the offline rules where defined. The
  Imagination choice avoids leaking hidden virtues through the choice list.
- Consequences: Imagination is a documented online deviation.
- Reconsider if: the design defines how hidden virtues should be chosen.

## D-003 — Disasters stay offline

- Date: 2026-10-07
- Status: active
- Decision: the online deck excludes the four disaster cards.
- Reason and evidence: not implemented on the server; out of the current
  scope.
- Consequences: online games differ from offline when disasters would occur.
- Reconsider if: disasters become a priority.

## D-004 — Online client on EgComponents v0.1.4, generated scene

- Date: 2026-10-07
- Status: active
- Decision: pin EgComponents core/motion/ui/testing to tag v0.1.4 (lock hash
  `d4c063f1`). `OnlineMVP.unity` is generated by `BusaraOnlineSceneBuilder`
  with Eg `UIRoot` pages, saved prefabs and baked sprites; it is not edited by
  hand. A SceneAudit test guards it.
- Reason and evidence: authored, inspectable scenes instead of runtime-built
  canvases; EditMode 58/58 and two-browser 4/4 pass on the new scene.
- Consequences: Eg boots automatically before every scene, offline ones
  included, using default settings (no `Resources/Eg/EgSettings`).
- Reconsider if: Eg boot affects offline scenes or a newer Eg tag is needed.

## D-005 — One online theme from the authored art

- Date: 2026-10-07
- Status: active
- Decision: `OnlineTheme` holds the palette (olive-slate surfaces, charcoal
  wells, amber/ember edges, warm text), typography (Poppins, Share Tech
  accents) and layout. Board slots sit over the authored `Board.png` wells.
- Reason and evidence: derived from `Background.png` and `Board.png`.
- Consequences: new online UI must use the theme and prefabs, not ad-hoc colours.
- Reconsider if: the offline UI adopts a different art direction.
